READ-ONLY

Hubungkan MG-30, lalu baca 10 record NAM untuk memeriksa respons perangkat.

Batasan saat ini: reader ini memeriksa apakah record slot dapat dibaca dan menyimpan fingerprint payload untuk analisis. Nama profil serta status terisi/kosong belum ditetapkan karena format recordnya masih perlu didekode. Tidak ada data yang ditulis ke perangkat.

Profil NAM lokal

File dibaca di perangkat ini; tidak mengunggah atau mengirim model ke MG-30.

LOCAL ONLY
Belum ada profil yang diperiksa. Pilih file .nam untuk melihat arsitektur, sample rate, metadata, dan bobot submodel.
Batasan: fitur ini hanya membaca metadata dan struktur file. Tidak mengirim NAM ke perangkat, tidak melakukan konversi .namb, dan tidak mengubah preset hardware. Penanda A2-Lite berbasis kecocokan struktur dengan sampel yang sudah kamu uji di MG-30.
