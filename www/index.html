NAM / PROFILE LAB

Native NAM Profile

Slot NAM di perangkatMembaca 10 record melalui SysEx; operasi ini hanya membaca data.READ-ONLY ·

Nama NAM akan dibaca otomatis setelah MG-30 tersambung. Tombol baca ulang tetap tersedia untuk menyegarkan hasil.

Batasan pembacaan: aplikasi membaca nama/metadata 128-byte untuk setiap slot dengan dua putaran pemeriksaan agar hasil stabil. Protokol ini tidak membaca kembali bobot model, jadi nama yang terbaca tidak membuktikan bobot model masih utuh. Operasi pembacaan tidak menulis data ke MG-30.

THIRD PARTY / USER IR

Import IR ke Third Party

Impor WAV ke jalur USER IR pada NUX MG-30 Gen 2. Di aplikasi/perangkat, jalur ini tampil sebagai Third Party; menu COLLECTION adalah jalur terpisah.

1. Pilih file IR untuk Third Party / User

WAV RIFF, mono/stereo. PCM 8/16/24/32-bit atau Float32; 8–192 kHz akan dikonversi ke 48 kHz. Stereo memakai kanal kiri.

EXPERIMENTAL

Parameter 71 teramati pada capture QuickTone c414_cap_45_dc; makna field dan pemetaan ke slot tujuan fisik belum terverifikasi.

Paket belum divalidasi. Pilih file WAV terlebih dahulu.

Belum dimulai

Belum ada file WAV yang dipilih.

Peringatan pengujian. Target halaman ini adalah jalur USER IR / Third Party dengan rangkaian 10/09/11, bukan rangkaian 6A/6C/6B yang terlihat pada capture aktivitas Collection. Aplikasi memakai parameter transfer 1 karena nilai itu teramati pada capture impor User QuickTone. Query konteks yang terpisah tidak muncul pada capture impor User yang kita miliki, sehingga tidak dipakai sebagai prasyarat. Makna parameter dan pemetaannya ke nomor slot fisik masih belum dipastikan. ACK bukan bukti bahwa IR sudah muncul dalam daftar. Cadangkan data penting dan pastikan target uji aman sebelum mengirim; transfer terputus dapat meninggalkan data parsial.
