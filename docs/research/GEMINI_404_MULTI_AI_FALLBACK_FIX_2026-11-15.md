# Gemini 404 / Multi-AI fallback correction
Date: 2026-11-15
Branch: `feature/multi-ai-free-tone-architect`
Related PR: #4

## Evidence from the user's screenshot

The AI assistant displayed:
`gemini: Provider rejected the request. Check the selected model and request settings. [404 /api/v1/ai/tone-plan]`

The Auto team status also showed Gemini, Groq and OpenRouter model choices, and automatic fallback was enabled.

## Corrected diagnosis

The route `POST /api/v1/ai/tone-plan` exists in `cloud-worker/src/index.js` and `cloud-worker/worker.js` in both the feature branch and its base branch. The deployed Worker itself was not directly inspected, so deployment drift cannot be asserted.

The exact error text is generated by the Worker's `safeProviderError(upstream.status)` when an upstream provider rejects the generation request with HTTP 404. A missing Worker route would instead return `Cloud API route not found.` The screenshot therefore points to an upstream Gemini model/request 404, not evidence that the Worker route is absent.

The Multi-AI client bug was in `isRetryableProviderError()`: it treated 408/425/429/498/500/502/503/504 as retryable but omitted a provider-specific 404. Consequently `invokeFreeTeam()` stopped after Gemini returned 404, even though the already-resolved free team also contained Groq/OpenRouter.

## Fix committed

Commit: `2a90ddf28671fb027b808172172e2397e5ac2b28`
- Treat only the specific upstream message `Provider rejected the request ... 404` as retryable.
- Keep a generic `Cloud API route not found ... 404` non-retryable, so a broken gateway route is not masked and does not waste calls to every provider.
- Existing `invokeFreeTeam()` then tries the next configured free provider when Automatic fallback is enabled.
- GPT is not part of the free team and cannot be reached by this fallback.
- Added regression assertions for provider-specific 404 vs missing-route 404.

## Protected scope

No change to `cloud-worker/src/index.js`, `cloud-worker/worker.js`, `www/cloud-api.js`, Worker secrets, Cloudflare configuration/deployment, MIDI dispatcher/CC mapping, NAM, IR import or preset codec. Only AI client fallback classification and its tests changed for this fix.
