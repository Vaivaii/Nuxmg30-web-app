## Models intentionally not replaced

The archives do not contain a dedicated reference for these current models, so their previous artwork renderer is left in place: `RVB / Damp`, `DLY / Phi Delay`, `MOD / CE-2`, `MOD / Detune`, all WAH models and VOL. No substitute logo or invented product identity is added.

## Rendering and integration notes

- The 52 ZIP images plus the separately supplied NF-1 image map to 53 dedicated local SVG references.
- The source photographs remain research references only; the app renders its own vector shapes and text. No remote image URLs or embedded source photos are used.
- The artwork module is `www/pedal-reference-artwork.js` and is called by the existing `renderGearSvg()` path in `www/index.html`.
- The renderer is visual-only. It does not read or modify MIDI state, SysEx bytes, parameter mapping, model indices or device communication.
- Text wordmarks are reconstructed as SVG text with common system-font fallbacks rather than distributed proprietary font files. Small differences in script/logo typography can therefore remain between devices.
