## Models requiring more specific confirmation

- NUX IMAGE variants are capture/model labels, not necessarily separately named commercial products. A closest hardware family may be used only when the capture's basis is documented.
- NAM slots are user-loaded Neural Amp Modeler captures. Unless the user supplies the captured amp identity or a photo, the artwork must be labeled as a neutral user-NAM skin rather than attributed to a real manufacturer.
- Some abstract algorithm names (for example Studio Comp, Para EQ, Modulation, Reverse, Hall, Shimmer) do not correspond to one unique pedal. Use a family-style control surface rather than inventing an exact product.
- If a listed third-party product mapping cannot be verified, keep the SVG as an interpretive design and mark the reference as unconfirmed.

## Implementation guardrails

- Artwork is original inline SVG, not copied product photos or remote image embeds.
- Every model should be mapped to its physical family and control arrangement before drawing.
- AMP/FX audio model names, MIDI mapping, parameter indices, preset synchronization, NAM/IR transfer and device communications remain untouched.
